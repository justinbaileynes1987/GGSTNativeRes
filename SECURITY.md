# Security

GGSTNativeRes is a DLL that runs inside the game, so security problems matter. If you find one,
please report it privately through
[GitHub's private vulnerability reporting](https://github.com/justinbaileynes1987/GGSTNativeRes/security/advisories/new)
rather than in a public issue.

**Only download GGSTNativeRes from this repository's
[Releases page](https://github.com/justinbaileynes1987/GGSTNativeRes/releases) or its official
[GameBanana page](https://gamebanana.com/mods/723773)** (both host the same file), and check the
SHA-256 hash listed on the release. The build is reproducible, so you can also rebuild it from
source and compare (see the README). Copies hosted anywhere else, especially repackaged
"installers" or `.exe` files, are not from this project.
